Aplicativo de Chat: Zap da Empresa

Comunicação em tempo real com Python e Flet.

Ver script (abre em nova aba)

Para que serve

O Zap da Empresa é um aplicativo de chat em tempo real, desenvolvido com a biblioteca Flet em Python. Ele permite que vários usuários interajam em uma sala de chat, com funcionalidades simples e feedback visual sobre mensagens e novas entradas.

É um exemplo de como a tecnologia pode facilitar a comunicação de forma prática e intuitiva.

Como foi feito

  • Linguagem: Python.
  • Biblioteca: Flet, para criar interfaces interativas.
  • Sistema PubSub: sincroniza as mensagens em tempo real.
  • Interface: AlertDialog, Column, Row e ElevatedButton.

Como usar

  1. Instale o Python

    Use a versão 3.9 ou superior.

  2. Instale o Flet

    pip install flet

  3. Execute o arquivo principal

    python main.py

  4. Abra no navegador

    Acesse o endereço http://localhost:8000.

  5. Entre no chat

    Clique em “Iniciar Chat”, informe seu nome no pop-up e comece a enviar mensagens.
