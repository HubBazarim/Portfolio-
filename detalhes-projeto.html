Problema

Automatizar uma tarefa repetitiva: o cadastro de produtos em um sistema online.

O projeto foi desenvolvido durante minhas aulas de Python da Hashtag, onde aprendi a usar a biblioteca PyAutoGUI para automatizar tarefas no computador. A ferramenta simula ações como escrever textos, pressionar teclas, clicar e fazer combinações de teclas.

Dados utilizados

Uma base de produtos em CSV, carregada com Pandas, com código, marca, tipo, categoria, preço unitário, custo e observações de cada item.

Processo

  1. Entrar no sistema da empresa

    Na aula, o caminho ensinado foi abrir o Windows Explorer e, em seguida, o Google Chrome. Achei mais eficiente abrir diretamente o navegador padrão, qualquer que seja, usando a função subprocess.run(). Outra alternativa seria a biblioteca webbrowser, que também abre um link no navegador padrão:

    import webbrowser
webbrowser.open(link)  # abre o link no navegador padrão

  2. Fazer login no sistema

    O PyAutoGUI simula o preenchimento dos campos de e-mail e senha no formulário de login e, em seguida, o clique no botão de login.

  3. Importar a base de produtos

    A base a ser cadastrada é carregada de um arquivo CSV com Pandas, o que permite manipular os dados de forma eficiente.

  4. Cadastrar os produtos automaticamente

    O robô percorre cada linha da tabela e preenche os campos correspondentes no sistema (código, marca, tipo, categoria, preço unitário, custo e observações). Depois envia o formulário e repete o processo.

  5. Repetir até o fim da lista

    Após cada envio, o robô rola a página para cima, preparando a tela para o próximo cadastro.

Resultado e aprendizados

O robô percorre a base inteira: preenche, envia e repete o cadastro até o último produto da lista.

Essa aula foi fundamental para o meu aprendizado no uso do PyAutoGUI, que se mostrou uma ferramenta muito interessante para a automação de tarefas repetitivas.

Observações importantes

  • Posições dos cliques: as coordenadas usadas para clicar nos campos podem variar conforme a resolução do monitor e a interface do sistema. Se necessário, ajuste os valores de x e y nas funções pyautogui.click().
  • Parar o programa: para interromper o robô durante a execução, basta mover o mouse para o canto superior esquerdo da tela. É uma função de segurança do PyAutoGUI chamada FAILSAFE.
